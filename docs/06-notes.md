# 注意事项与已知限制

在使用、修改或二次开发本项目前，请阅读以下事项。

## 1. 编码与编辑

- `src/*.cpp`、`src/*.h`、`third_party/USB9825.h` 为 **GBK 编码**，包含中文注释与界面字符串；
- `src/*.ui`、`src/*.sln`、`src/*.vcxproj` 为 **UTF-8**（`.sln`/`.vcxproj` 带 BOM）；
- 源码中启用了 `#pragma execution_character_set("utf-8")`，保证字符串字面量按 UTF-8 编译；
- **请勿用编辑器整体转码 GBK 源文件**，否则中文注释与界面文案会乱码，导致显示异常。若需转换，请同步调整 pragma 与字符串。

## 2. 硬件与驱动

- 程序轮询设备号 `0~31`，连接**第一块**可用的 USB9825；若有多块设备，需注意接入顺序。
- 采集卡驱动需按厂商说明安装；`USB9825.dll` 版本需与驱动/SDK 匹配。
- 启动时应确认「采集卡」状态灯为绿；红灯表示未连接，需检查设备与驱动。
- `connect_to_card()` 中 `break` 位于 `return 1` 之后，属不可达语句，不影响功能。

## 3. 算法与阈值

- 容差带基于 `μ ± 3σ`，假设样板信号近似正态分布且过程稳定；对非平稳信号需重新评估阈值策略。
- 当前 `learning_data_analysis()` 中的标准差计算在循环内对 `total_SD` **逐次覆盖而非累加**：

  ```cpp
  for (int index_sd = 0; index_sd < learn_table_row_count; index_sd++) {
      total_SD = pow(avg_H[...] - table_vector_H[...][index_sd][index_h], 2);
  }
  standardD_H[...] = sqrt(double(total_SD) / double(learn_table_row_count));
  ```

  结果等价于取**最后一个样本**的偏差，而非全部样本方差。**这是已知的实现限制**：如需严格统计意义的标准差，应将 `=` 改为 `+=` 并采用样本标准差公式（分母 `n-1`），同时重新标定阈值。修改后务必用现场数据回归验证。
- 样本较少或样板本身含缺陷时，容差带会被污染，需保证学习样板的代表性。
- 实时检测曲线 (`diag_signal`) 与容差带 (`listH_low/high`) 的可视化分属不同图表对象；若要实现自动判异输出，需在 `curr_signal_thread()` 中补充逐点越界判定逻辑。

## 4. 线程与资源

- `learnning_process()` 创建的学习/控制线程使用 `while(1)` 循环，程序退出时未显式 `quit()/wait()`；长时间运行或频繁重启时请注意线程资源。
- `curr_signal_thread()` 中 `QTimer` 以 1 ms 触发，实际受系统定时器精度限制；`qApp->processEvents()` 用于避免界面冻结，但不宜在高负载下过度调用。
- 多个 `QTimer` 与 `QChart` 对象以 `new` 创建且未设置父类或释放，属原型阶段实现；生产化时建议纳入父子所有权管理。

## 5. 外部接口

- TCP Server 监听 `0.0.0.0:12345`，无鉴权机制，**不应直接暴露于公网**；现场部署建议限制在受控内网并配置防火墙。
- Windows 事件名 `FELIX_WELD_SIGNAL_001` 为上位机与控制器的耦合约定，任一侧修改需同步另一侧。
- JSON 解析使用 `QJsonDocument::fromJson`；示例返回报文中的时间为占位字符串，实际项目中应填充真实时间。

## 6. 数据与合规

- 仓库仅提供脱敏截断示例数据，用于格式演示；真实生产数据请勿直接提交到公开仓库。
- 本仓库已清除非项目相关的品牌标识与署名，统一以 **Felix** 为作者与归属。新增代码或文档请保持这一约定。
- USB9825 SDK 的二进制文件受第三方许可约束，需通过正规渠道获取；本项目不分发这些二进制文件。
